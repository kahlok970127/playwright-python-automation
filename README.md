# Playwright Python Automation

A practice project for learning UI automation testing using **Playwright**, **Python**, and **Pytest**. This repository demonstrates a basic test automation framework following the **Page Object Model (POM)** design pattern.

## Tech Stack

- Python
- Playwright
- Pytest
- Page Object Model (POM)

## Project Structure

```
playwright-python-automation/
│
├── page/              # Page Object classes
├── test/              # Test cases
├── conftest.py        # Pytest fixtures and configuration
└── .gitignore
```

## Features

- Page Object Model (POM)
- Pytest test framework
- Browser automation with Playwright
- Reusable page objects
- Practice automation test cases

## Installation

```bash
git clone <repository-url>
cd playwright-python-automation

pip install -r requirements.txt
playwright install
```

## Run Tests

Run all test cases:

```bash
pytest
```

Run with verbose output:

```bash
pytest -v
```

## Learning Objectives

This project is created for learning and practicing:

- Playwright fundamentals
- Element locators
- Page Object Model (POM)
- Pytest fixtures
- Test automation framework design
